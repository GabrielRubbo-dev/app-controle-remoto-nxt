
# 📱 Controle Remoto NXT

> App para controlar o carrinho/robô LEGO Mindstorms NXT, via Bluetooth.

---

## 🎯 Objetivo
Conectar no LEGO Mindstorms NXT e caso seja montado o carrinho/robô controlá-lo. 

## ✨ Funcionalidades
- Botão de conexão de desconexão.
- Botão para ir para frente.
- Botão para ir para trás.
- Botão para ir virar a esquerda.
- Botão para ir virar a direita.

## ️ Tecnologias Utilizadas
- **MIT App Inventor** (Desenvolvimento em blocos)
- **Bluetooth**
- **LEGO Mindstorms NXT**
- **GitHub** (Hospedagem do projeto)

## 📂 Como testar este aplicativo?
1. Baixe o arquivo `.aia` disponível neste repositório.
2. Acesse o [MIT App Inventor](http://ai2.appinventor.mit.edu/).
3. Clique em **Projetos > Importar projeto (.aia) do meu computador**.
4. Selecione o arquivo baixado para visualizar e testar o código!
